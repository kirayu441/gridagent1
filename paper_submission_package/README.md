# 论文提交包说明

本文件夹用于整理 GridAgent 正式论文投稿所需的完整材料。

当前采用的原则是：

- 先尽可能完整地收集核心内容；
- 后续再根据投稿要求做精简；
- 优先保证方法、实验、结果和复现材料齐全。

现阶段，这个目录主要用于集中整理以下内容：

- 方法说明材料
- 实验复现材料
- 结果验证材料
- 对比实验材料
- 论文写作支撑材料

## 当前目录结构

| 文件夹 | 当前用途 |
|---|---|
| `scripts/` | 正式实验链路使用的核心原始脚本源代码 |
| `data/` | 输入数据与最小可复现实验数据 |
| `result/` | 最终实验结果、标准化结果与最终报告 |
| `stage_result/` | 分阶段可复现包与分阶段输出 |
| `compare/` | 对比实验代码与对比实验结果 |
| `docs/` | 说明文档、实验记录、报告与论文辅助材料 |
| `configs/` | 数据集配置、实验配置与最终链路配置记录 |
| `requirements/` | 环境依赖文件与版本说明 |
| `figures/` | 论文最终插图与图形导出结果 |
| `logs/` | 过程记录、清理记录与运行说明 |

## 各文件夹计划放置的内容

### scripts

计划放置：

- Stage1-Stage8 主链路核心脚本
- Stage6 模型源码
- 一键复现或关键复现实验脚本

### data

计划放置：

- 正式实验链路使用的最小必要输入数据
- 用于复现的整理后数据文件

### result

计划放置：

- 最终标准化结果
- 最终实验报告
- 偏论文写法的结果总结

### stage_result

计划放置：

- `gridagent_final` 中整理好的分阶段包
- 各阶段正式输出与说明材料

### compare

计划放置：

- 方法对比脚本
- 消融实验脚本
- 对比实验结果表格与总结

### docs

计划放置：

- 项目整体说明
- 数据来源与许可说明
- 论文支撑性说明文档
- 实验组织与整理文档

### configs

计划放置：

- 数据集配置文件
- 最终链路选择记录
- 实验参数快照

### requirements

计划放置：

- 总体 `requirements.txt`
- 分阶段依赖文件
- 环境搭建说明

### figures

计划放置：

- 论文最终图件
- 适合直接入文的导出图表

### logs

计划放置：

- 整理过程记录
- 清理说明
- 实验运行说明

## 当前状态

本提交包目前处于结构搭建阶段。

后续会逐步把已有的：

- 核心脚本
- 输入数据
- 分阶段结果
- 最终结果
- 对比实验材料

按用途整理进对应目录中。

最终提交版本将在此基础上进一步精简，形成适合正式论文投稿与结果归档的完整材料包。
