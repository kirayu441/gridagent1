# data 目录说明

本目录用于存放论文投稿包中的正式实验输入数据。当前优先收录主实验链路中已经确认使用的数据文件，包括广东 2024 时序数据包和 IEEE 118 全节点电网拓扑文件。

## 一、当前目录结构

```text
data/
├─ formal_guangdong_2024/
│  ├─ aligned_merged.csv
│  ├─ DPGMM_input.csv
│  ├─ TRIM_input.csv
│  └─ integrity_report.json
└─ topology/
   └─ ieee118_full/
      └─ grid_topology.json
```

## 二、正式时序数据包：`formal_guangdong_2024/`

该目录保存广东 2024 正式实验使用的年度时序数据。几份文件并不是彼此无关，而是面向不同实验用途整理出的不同层次数据。

### 1. `aligned_merged.csv`

这是广东 2024 数据包的基础合并时序表，可视为整个正式数据集的底表之一。  
它已经完成了多源数据的逐小时对齐与合并，主要包含时间戳、风电出力、光伏出力、负荷、辐照度、温度、风速等字段。

这份文件更偏向“数据构建结果”或“底层总表”。  
如果后续需要追溯 `TRIM_input.csv` 或 `DPGMM_input.csv` 的来源，通常应从这张表开始理解。

### 2. `DPGMM_input.csv`

这是 Stage1 风光不确定性建模的专用输入文件。  
它只保留了风电和光伏出力两列，用于 Rolling DPGMM 或 Conditional Rolling DPGMM 对风光联合不确定性进行建模。

这份文件的设计目标是让 Stage1 只关注最核心的风光联合序列，而不引入负荷或辅助气象变量。  
它与 `TRIM_input.csv` 配套使用，其中本文件提供风光数值序列，`TRIM_input.csv` 提供时间索引和其他链路所需信息。

### 3. `TRIM_input.csv`

这是正式实验链路中的主输入文件之一，也是后续 Stage1-Stage7 最重要的通用输入表之一。  
它在 `aligned_merged.csv` 的基础上增加了 `HourOfDay`、`DayOfYear`、`Month`、`Weekday` 等时间特征，因此更适合直接作为后续实验模块输入。

相比 `aligned_merged.csv`，这份文件更偏向“实验就绪输入”。  
也就是说，`aligned_merged.csv` 强调数据整合与追溯，`TRIM_input.csv` 强调后续模块直接调用。

### 4. `integrity_report.json`

这是广东 2024 正式数据包对应的数据完整性检查报告。  
其中通常记录数据行数、字段检查、缺失情况或构建结果摘要，便于说明正式实验输入数据经过了完整性校验。

在论文投稿或复现实验说明中，这份文件很有价值。  
它可以用来支撑“输入数据经过预处理与质量检查”这一点，而不是只给出结果文件本身。

## 三、正式实验拓扑：`topology/ieee118_full/`

### `grid_topology.json`

这是正式论文实验实际使用的 IEEE 118 全节点电网拓扑文件。  
它定义了节点、线路、发电机等拓扑结构信息，是 Stage2 及后续故障生成、调度优化、韧性评估和 GNN 预警模块的重要基础输入。

本项目当前的正式实验思路是：  
使用广东 2024 的时序数据作为风光、负荷和天气输入，同时使用 IEEE 118 全节点拓扑作为电网结构载体。

## 四、这些文件之间的关系

当前这 5 个文件可以按如下逻辑理解：

```text
多源原始数据
   ↓ 对齐、合并
aligned_merged.csv
   ├─> DPGMM_input.csv   （Stage1 风光不确定性建模输入）
   └─> TRIM_input.csv    （Stage1-Stage7 主实验链路输入）

formal_guangdong_2024 时序数据
   +
ieee118_full 电网拓扑
   ↓
正式论文实验输入组合
```

## 五、当前收录原则

当前 `data/` 目录按照“先保留主实验必需数据，后逐步补充对比与扩展数据”的原则整理：

1. 先收录正式链路实际使用的数据包；
2. 先收录正式实验实际使用的 IEEE118 全节点拓扑；
3. 暂不放入重复、旧版默认输出或大量中间备份文件；
4. 后续如需补充缩规模拓扑、扩展拓扑或对比实验数据，再逐步加入。
