# Stage6 方案A（仅 c3po_ref）实验汇报

## 1. 汇报范围

- 本文仅分析 `c3po_ref` 标签下的方案A实验结果。
- 实验目录：`results/early_warning/stage6_planA_full_20260415_20260415_002847`。
- 统计来源：`all_runs.csv` 中 `label_method=c3po_ref` 的 20 条有效运行（4模型 × 5 seeds）。

## 2. 实验目标

- 在同一标签体系（c3po_ref）下，比较四种模型组：
  - `A0`: Baseline GNN（无 MetaPath）
  - `A1`: MetaPath 固定注意力（Fixed）
  - `A2`: MetaPath 全局自适应注意力（Adaptive Global）
  - `A3`: MetaPath 上下文自适应注意力（Adaptive Context）
  
- 目标是验证：引入 MetaPath 是否稳定增益，以及两种自适应变体是否优于固定 MetaPath。

  ### A0：Baseline GNN

  A0 作为基线模型，不启用 MetaPath 分支，直接采用普通图神经网络进行线路风险预测。其作用是提供一个不依赖高阶语义路径建模的基础参照，用于判断仅靠常规节点消息传递与边特征建模，是否已经足以支撑 Stage6 的风险预警任务。A0 对应的是“无 MetaPath 增强”的最基础设置。

  ### A1：MetaPath + Fixed Attention

  A1 在 A0 的基础上引入 MetaPath 分支，并采用固定语义注意力机制对不同元路径进行聚合。该组的意义在于验证：在普通 GNN 之外加入高阶结构语义后，是否能够进一步提升线路风险预测效果。

  ### A2：MetaPath + Adaptive Global Attention

  A2 在 A1 的基础上，将固定语义加权扩展为全局自适应加权。具体来说，模型会根据当前整体的元路径表征，为不同元路径引入全局偏置，从而使不同路径的重要性能够随当前图状态发生调整。A2 的重点不在于针对单条边做精细条件化，而在于捕捉“当前整体图状态下，哪类元路径整体更值得关注”。因此，它可以看作从固定加权走向自适应加权的第一步。

  ### A3：MetaPath + Adaptive Context Attention

  A3 在 A1 的基础上进一步引入上下文条件化机制，将边的动态特征显式纳入语义注意力打分过程。与 A2 的全局自适应不同，A3 更强调“针对当前这条边、当前这一时刻的上下文信息”，动态调整各类元路径的重要性。因而，A3 更接近“路径重要性随局部风险状态和动态条件变化”的建模思路，也更符合 Stage6 在不同时间和不同风险情境下进行细粒度风险预警的目标。

  

  - A0 用于回答“是否需要 MetaPath 分支”；
  - A1 用于回答“固定语义注意力的 MetaPath 是否有效”；
  - A2 用于检验“全局层面的自适应语义加权是否优于固定权重”；
  - A3 用于进一步检验“结合边动态上下文的条件化加权是否能够带来更细粒度的收益”。

  

## 3. 控制变量与统一配置

- 标签张量：固定为 `c3po_ref`。
- 随机种子：`42,43,44,45,46`。
- 数据与切分：同一输入数据、同一 `train_ratio=0.7`。
- 训练主配置：`hidden_dim=80, epochs=700, lr=0.0042, weight_decay=0.00005`。
- MetaPath公共配置：`metapath_topk=4`。
- 为了聚焦架构差异，本轮关闭策略项：
  - `risk_weight_alpha=0, risk_weight_beta=0`
  - `metapath_warmup_epochs=0`
  - `metapath_gate_reg_lambda=0`

## 4. 评估指标

- `val_mae`：验证集平均绝对误差（越低越好）。
- `best_val_mse`：训练过程中最佳验证 MSE（越低越好）。
- `val_high_risk_mae`：验证集高风险子集 MAE（越低越好）。
